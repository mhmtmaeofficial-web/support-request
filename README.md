# Support Playbooks

This repository contains internal support playbooks and customer-facing response
templates for common billing and account issues.

## Playbooks

- Unauthorized charges (refund + payment method removal):
  - `docs/support/unauthorized-charges.md`

## Notes

- Do **not** commit customer PII (emails, card details, addresses) into this
  repository. Use placeholders like `<customer_email>` and store case-specific
  data only in the ticketing system.
